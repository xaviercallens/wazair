## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please do not report it publicly.

Instead, please send an email to the project maintainers with a detailed description of the issue, the steps you took to reproduce it, and any potential impact you have identified.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If a fix is required, we will work to provide it as quickly as possible.
