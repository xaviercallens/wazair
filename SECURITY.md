# Security Policy

## Supported Versions

Currently, only the latest version of `wazair` is supported with security updates.

## Reporting a Vulnerability

We take the security of `wazair` seriously. If you believe you have found a security vulnerability in this repository, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to **security@wazair.com**.

Please include the following information in your report:
- The type of vulnerability.
- A description of the vulnerability.
- Steps to reproduce the issue.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.
