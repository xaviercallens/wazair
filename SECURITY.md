# Security Policy

## Supported Versions

The following versions of wazair are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability in wazair, please report it to us as described below.

Please do not report security vulnerabilities through public GitHub issues. Instead, please report them to `security@wazair.com`.

You should receive a response within 48 hours. If for some reason you do not, please follow up via email to ensure we received your original message.
